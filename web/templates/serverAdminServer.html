Den Server moderieren (Meldungen, Galerie, Events …) die Moderatoren auf der Verwaltungsseite des Servers.

Plugin einrichten

  1. {% if plugin_available %} MCDataLink.jar herunterladen {% else %} MCDataLink.jar (Download gerade nicht verfügbar) {% endif %} und in den plugins-Ordner deines Servers legen (Spigot/Paper 1.13+).
  2. Server einmal starten, danach plugins/MCDataLink/config.yml so befüllen: 
    key: {{ server.server_key }}
host: {{ plugin_host }}
port: {{ plugin_port }}

    Die Verbindung ist immer verschlüsselt (TLS). Dafür braucht es MCDataLink ab Version 3.12 – ältere Plugins werden abgewiesen, einfach die neue Datei herunterladen.

  3. Server neu starten. Sobald das Plugin verbunden ist, erscheint hier „Plugin verbunden“.

Der Key ist geheim. Wenn er in falsche Hände gerät, erzeuge einen neuen.
